## 2. 真机验收矩阵

最低要求：

- 一台 Android 12 或更高版本真机。
- 一副蓝牙 A2DP 耳机。
- 一副有线耳机。

建议补充：

- Android 14/15。
- BLE Audio 耳机。
- USB-C 耳机。
- 至少两个不同 OEM。

## 3. 功能用例

| ID | 场景 | 步骤 | 预期结果 |
|---|---|---|---|
| ALM-01 | 新建单次闹钟 | 创建 2 分钟后闹钟并保存 | 首页显示时间、名称和倒计时；到点触发 |
| ALM-02 | 编辑闹钟 | 修改时间、名称和铃声 | 旧实例取消，新实例按新配置触发 |
| ALM-03 | 删除闹钟 | 删除已启用且含 Snooze 的闹钟 | 当前和所有待触发实例取消，列表中消失 |
| ALM-04 | 启停 | 关闭再开启每周闹钟 | 关闭时不再触发；开启后重算下一次 |
| ALM-05 | 多闹钟 | 两个闹钟相隔 10 秒触发 | 第一只播放；第二只排队；第一只关闭后才播放第二只 |
| AUD-01 | 蓝牙耳机 | 连接 A2DP 耳机、后台锁屏触发 | 先显示路由确认；声音只在耳机；扬声器不响；震动正常 |
| AUD-02 | 有线耳机 | 连接 3.5mm/USB-C 耳机触发 | 声音只在耳机；扬声器不响 |
| AUD-03 | 无耳机 | 未连接任何耳机触发 | 使用系统默认闹铃输出并震动 |
| AUD-04 | 耳机断开 | 响铃中拔出耳机或关闭蓝牙耳机 | 立即停止声音，不持续外放；震动继续；显示断开状态 |
| AUD-05 | 路由拒绝 | 在系统异常/OEM 限制下无法确认耳机 | 保持静音、震动、显示路由失败和重试入口 |
| AUD-06 | 重试 | 路由失败后重新连接耳机并点重试 | 再次确认路由后才播放 |
| AUD-07 | 音频抢占 | 响铃中开始通话或另一应用抢占永久焦点 | 停止当前音频，不主动外放；会话保持并震动 |
| VOL-01 | 音量上限 | 设置 40%，系统媒体音量为 100% | 应用声音明显受限，系统音量数值不被应用修改 |
| VOL-02 | 音量边界 | 拖动至 10% 和 80% | 可保存并重新进入后保持；不能超出范围 |
| SNO-01 | Snooze | 点击“延后 5 分钟” | 当前停止；5 分钟后再次响铃；原重复规则不变 |
| SNO-02 | 重复 Snooze | Snooze 后再次点击 Snooze | 只影响当前实例，仍不修改原规则 |
| SNO-03 | 关闭 Snooze | 关闭闹钟 Snooze 开关后触发 | 响铃页不显示延后按钮 |
| FILE-01 | 导入 MP3 | 从系统选择器导入 MP3 | 复制成功、可试听、选择后触发播放 |
| FILE-02 | 导入 WAV/M4A/AAC/OGG/FLAC | 分别导入常见样本 | 平台可解码时成功；不可解码时显示明确提示 |
| FILE-03 | 不支持格式 | 选择文本或视频文件 | 不创建铃声记录，显示格式提示 |
| FILE-04 | 原文件删除 | 导入后从文件管理器删除原文件 | 闹钟仍能播放私有副本 |
| FILE-05 | 私有文件损坏 | 开发调试中破坏私有副本后触发 | 回退内置提示音、继续震动并提示重新选择 |
| SCH-01 | 后台触发 | HOME 后锁屏等待 | 精确权限开启时准点启动服务 |
| SCH-02 | 进程重建 | 系统回收进程后等待 | 系统广播重新启动服务；Room 状态恢复 |
| SCH-03 | 设备重启 | 重启并解锁设备 | 启动接收器重建启用闹钟 |
| SCH-04 | 时间/时区 | 修改系统时间或时区 | 所有启用闹钟重算 |
| SCH-05 | 权限拒绝 | 关闭精确闹钟权限后创建/等待 | 显示降级警告；使用尽力调度 |
| AUTO-01 | 自动静音 | 不操作并持续响铃 10 分钟 | 声音与震动停止，写状态通知 |
| AUTO-02 | 服务恢复不重置上限 | 响铃中重建服务 | 仍按首次响铃的绝对 10 分钟截止时间停止 |
| STOP-01 | 手动停止 | 响铃中点击页面或通知“停止响铃” | 音频、震动和响铃通知立即停止，服务退出 |
| STOP-02 | 编辑页停止 | 对应闹钟响铃时进入数字时间卡片并停止 | 只显示当前闹钟控制；声音、震动和通知停止，同闹钟排队实例取消，重新进入不再响铃 |
| ALM-06 | 凌晨提前触发 | 00:25 启用当天 06:30 单次闹钟 | 只安排 06:30 实例，06:30 前不得响铃 |
| CNT-01 | 多个 Snooze | 为不同闹钟分别 Snooze | 每个临时实例独立，不互相覆盖 |
| PRI-01 | 隐私静态检查 | `aapt dump permissions app-debug.apk` | 不出现 `android.permission.INTERNET` |
| UI-01 | 大字体 | 系统字体放大后浏览首页、编辑页、响铃页 | 文本不截断或重叠，主要按钮可见 |
| UI-02 | 小屏 | 360dp 宽设备完成新建和 Snooze | 星期选择可横向滚动，操作可达 |

## 4. 发布阻断条件

以下任一情况阻止交付：

- APK 包含 INTERNET 权限或启用自动备份。
- 已连接耳机时应用主动将音频目标设置为扬声器。
- 耳机路由无法确认时仍正常放声。
- Snooze 修改原闹钟重复规则。
- 精确权限正常时后台闹钟普遍无法触发。
- 删除或损坏文件导致应用崩溃。
- 多个闹钟同时混音。
